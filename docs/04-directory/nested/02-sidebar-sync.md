# 嵌套子页 B：多级子目录与侧边栏同步机制

在纯 Markdown 母版仓库中，新增一篇子目录文档无需修改任何外部配置文件；而派生到各静态网站生成器后，要么必须同步手改配置文件（防“孤岛页”），要么接受自动生成侧边栏无法优雅指定中文分组名的局限，要么在文档目录内散落 `_category_.json` / `_index.md` / `_sidebar.md` 等控制文件。
