## 3. 核心杀手锏与架构妥协

1. **Rust 编译管线解决大型 React 文档慢构建痛点**：借助 Rspack 与 Rust 版 MDX 编译器，构建速度比传统 JS 打包管线快 5~10 倍。
2. **`_meta.json` 声明式目录编排 + 双标注兼容**：支持在各目录放置 `_meta.json` 控制排序与中文分组标题，并同时兼容 `:::tip` 容器与 GitHub `> [!NOTE]` 警报语法。
