# `hexo` 站点档案（Hexo · 图鉴扩展位）

- **预留子模块路径**：`sites/hexo`（与本档案 `docs/sites/hexo.md` 严格 1:1 对应）
- **上游官方仓库**：[`hexojs/hexo`](https://github.com/hexojs/hexo)
- **底层技术栈**：Node.js + EJS / Nunjucks / Pug 模板引擎

## 1. 生命周期定位（开始 / 活跃 / 废弃时间）

| 指标 | 时间节点与演进状态 |
| :--- | :--- |
| **开始时间** | **`2012-09-23`** 由 Tommy Chen 创立开源 |
| **活跃时间** | **`2013–2020` 为黄金活跃期**（`2013` 峰值达 `1,136` 次提交，`2019–2020` 仍有 `300–460` 次/年）；**`2021–2026` 稳定回落至每年 `40–90` 次低频维护** |
| **废弃 / 演进状态** | **核心未正式废弃**（维持基础安全与 Node 兼容更新），但大量早期三方主题已断更，且在**树状技术文档场景已被现代 SSG 替代** |

## 3. 核心特色与文档站局限

1. **时间线博客生态极其丰富**：围绕 `source/_posts/`、标签（Tags）与分类（Categories）构建了庞大的个人博客主题生态。
2. **Tag Plugins 私有方言与树状导航短板**：提示块使用 `{% note warning %}...{% endnote %}` 专有标签，跨平台不兼容，且缺乏原生多级产品文档侧边栏体系。
