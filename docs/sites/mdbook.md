## 3. 核心杀手锏与架构妥协

1. **`src/SUMMARY.md` 单文件定义整本书结构**：阅读顺序与章节层级 100% 由一份纯 Markdown 列表文件决定，若列表中的 `.md` 尚不存在，构建时甚至会自动创建骨架文件。
2. **专注线性书籍场景**：内置 `mathjax-support = true` 与新版 GFM `> [!NOTE]` 支持，但界面高度固定为电子书形态，不适合多维产品门户定制。
