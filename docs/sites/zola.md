## 3. 核心杀手锏与架构妥协

1. **Rust 版“人性化 Hugo”**：同样具备单二进制零外部依赖与毫秒级编译优势，但采用类 Jinja2 的 Tera 模板语法，比 Hugo 的 Go Template 更容易上手。
2. **目录与方言取舍**：沿用 `content/` + `_index.md` 分支章节约定，提示框等富文本扩展需编写 Tera Shortcode（`{% callout(type="warning") %}...{% end %}`）。
