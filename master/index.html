静态网站生成基准母版（Canonical Master *.md）

本目录（page2401.github.io/docs/）存放全站所有测试章节的唯一原始母版（Single Source of Truth）。母版严格使用不绑定任何特定生成器的 标准 GitHub Flavored Markdown（GFM）+ LaTeX 数学语法 + Mermaid 代码块 编写。

各个独立子模块仓库（sites/vitepress-v1、sites/vitepress-v2、sites/vuepress-v1、sites/vuepress-v2、sites/docsify-v4、sites/docsify-v5、sites/astro7-starlight）中的文档均由本母版派生适配（Derived）而来——凡是子模块与本母版存在差异的行，即为该框架特定大版本所要求的方言妥协或元数据侵入成本。
