3. 核心差异化特色与选型边界

  1. Python 开发者的个人博客经典：如果你熟悉 Jinja2 模板与 Python 脚本，希望快速构建带多语言翻译、Atom/RSS 订阅与代码高亮的静态技术博客，Pelican 依然轻巧可靠。
  2. 边界：与 Hexo、Jekyll 一样围绕“按时间发布的文章（Articles）”建模，不适合组织深层嵌套的产品 API 文档树。
