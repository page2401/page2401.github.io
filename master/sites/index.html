docs/sites/ 站点独立元数据 JSON、构建性能与 GitHub 活跃度总览（26 款）

本目录（docs/sites/）与仓库子模块目录 sites/<id> 严格保持 1:1 对齐，当前共收录 26 款主流静态网站生成器 / 大版本（包含 25 个跨语言同源实测子站 与 1 个纯云端 SaaS 历史档案位 gitbook），每个站点均成对维护两份文件：

  1. 结构化元数据与实测数据文件 docs/sites/<id>.json：
    • 站点自身元数据：websiteUrl（官方网站）、githubUrl（GitHub 源码地址）、packageUrl（包仓库地址）、tags（特性与流派标签数组）、lifecycle（开始 / 活跃 / 废弃时间）、libs（运行时、打包器、UI 框架、Markdown 引擎、代码高亮、全文检索、公式与图表库及 coreLibs / pinnedPackages）；
    • benchmark 节点（已挂载实测子站）：通过 npm run sync:benchmarks（scripts/measure-benchmarks.mjs）在同一环境空缓存实测的冷构建耗时（coldBuildMs）、总产物大小、HTML/JS/CSS/字体拆分、Gzip 体积、正文 <script> 数及离线搜索索引形态；
    • github 节点：通过 npm run sync:github（scripts/fetch-github-activity.mjs）查询 GitHub GraphQL API 持久化的仓库统计与 2008–2026 历年提交数。
  2. 深度剖析文档 docs/sites/<id>.md：自动读取同名 ./<id>.json 渲染元数据卡片、构建性能实测表与历年提交活跃度表格，并补充架构优劣与排障实录。
